# Daughter Dads Unite

Static website for [daughterdadsunite.org](https://daughterdadsunite.org) — cause apparel, 50% of profits donated to RAINN.

- Hosted on GitHub Pages (branch `main`, root), DNS on Cloudflare.
- Plain HTML/CSS, no build step needed to deploy. Edit the `.html` files directly.
- Products link to the Love and Care Store listings on Amazon.
